Jacob & Co. Landing Page is a frontend web development project created using HTML5 and External CSS. This project is inspired by the luxury design and watch collections of the Jacob & Co. brand. The webpage demonstrates different CSS concepts such as hover effects, simple selectors, combinators, layout structuring, display flex, positioning properties, fixed background attachments, and embedded video components.

This project helps in understanding how layout stacking, custom text alignment, display flex alignments, and multi-tier background scroll effects work in frontend web design. External CSS is used via index.css to manage structural sizing and design choices, keeping the index.html structure organized and highly readable. Google Fonts are also integrated to enhance the typography and premium aesthetic of the webpage.
